# knowbase-md

Текущая версия: **1.0.0**.

`knowbase-md` - простой сайт для публикации базы знаний из Markdown-файлов. Проект рассчитан на небольшие учебные материалы, инструкции и внутренние статьи, которые удобно хранить в папках и редактировать обычным текстовым редактором.

В репозиторий выкладывается только код сайта и документация. Рабочие статьи, изображения и другие медиафайлы лежат локально в `articles/` и не отправляются в GitHub.

## Возможности

- автоматическая сборка главной страницы по папкам внутри `articles/`;
- категории с названием, описанием и списком статей;
- Markdown-рендеринг с таблицами, списками, блоками кода и оглавлением;
- подписи к отдельным изображениям через синтаксис `![Подпись](media/file.jpg)`;
- поддержка LaTeX-формул через MathJax;
- поиск по названиям, описаниям и тексту статей;
- фиксированная нижняя навигация между соседними статьями раздела;
- сворачиваемое оглавление статьи;
- простая парольная защита отдельных статей;
- единый футер, favicon и статические стили без сборщика фронтенда.

## Быстрый запуск

Требуется Python 3.12 или совместимая версия Python 3.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe main.py
```

По умолчанию сайт запускается на `http://localhost/`, если в `.env` указан `PORT=80`. Для локальной разработки удобнее поставить, например:

```env
HOST=127.0.0.1
PORT=8000
```

После этого сайт будет доступен по адресу `http://127.0.0.1:8000/`.

## Структура проекта

```text
main.py              # HTTP-сервер, загрузка статей, рендеринг Markdown
static/style.css     # внешний вид сайта
static/site.js       # поиск, оглавление, раскрытие защищённых статей
static/site-icon.svg # SVG-иконка сайта
favicon.ico          # favicon
announcement.md      # необязательное объявление на главной
requirements.txt     # Python-зависимости
.env.example         # пример переменных окружения
CHANGELOG.md         # история версий
docs/                # документация по проекту
articles/            # локальный контент, не публикуется в GitHub
```

## Работа с контентом

Контент хранится в `articles/`. Каждая папка первого уровня становится разделом сайта. Внутри раздела можно хранить Markdown-статьи и папку `media/` с изображениями.

Минимальная структура раздела:

```text
articles/
  10-example/
    category.txt
    description.txt
    00-intro.md
    01-next-topic.md
    media/
      image.jpg
```

Подробнее: [docs/site-guide.md](docs/site-guide.md).

## Переменные окружения

Проект читает `.env` при запуске. Реальные пароли и серверные настройки не нужно коммитить.

Основные переменные:

```env
HOST=0.0.0.0
PORT=80
ARTICLE_PASSWORD_10_EXAMPLE=change-me
```

Имя переменной для пароля строится из имени папки раздела: верхний регистр, все не-буквенно-цифровые символы заменяются на `_`.

## Версионирование

Проект использует формат `MAJOR.MINOR.PATCH`.

- `MAJOR` меняется при несовместимых изменениях структуры сайта или формата контента.
- `MINOR` меняется при добавлении возможностей без поломки существующих статей.
- `PATCH` меняется при исправлениях ошибок, правках стилей и небольших улучшениях.

Текущая версия задаётся в `main.py` в переменной `SITE_VERSION` и отображается в футере сайта. История изменений ведётся в `CHANGELOG.md`.

## GitHub

Перед публикацией в GitHub статьи и медиа исключены через `.gitignore`:

```gitignore
articles/
```

Это значит, что GitHub-репозиторий содержит движок сайта, стили, скрипты и документацию, но не содержит учебные материалы.

Публикация:

```powershell
git remote add origin https://github.com/<логин>/knowbase-md.git
git push -u origin master
```
